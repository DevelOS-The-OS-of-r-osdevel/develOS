# Contributing to develOS

Thank you for contributing to develOS!

develOS is a community-driven operating system project. Contributions are welcome, whether you are fixing bugs, writing kernel code, working on drivers, improving documentation, testing the OS, or helping with tools.

## Branches

develOS uses two main branches:

- `main` - stable code
- `develop` - active development

Do not push directly to either branch.

## Creating a Branch

Create your branch from `develop`.

Use a clear name:

- `feature/keyboard`
- `feature/memory-manager`
- `fix/framebuffer`
- `docs/build-guide`
- `refactor/kernel`

## Making Changes

Keep each branch focused on one change.

Avoid mixing unrelated features or fixes into the same pull request.

Before modifying existing code, make sure your local branch is up to date.

## Pull Requests

All changes should be submitted through a pull request to `develop`.

Your pull request should explain:

- What changed
- Why it changed
- How it was tested
- Any known limitations

A maintainer will review the pull request before it is merged.

## Testing

Build and test your changes before opening a pull request.

If your change affects the kernel or hardware behavior, explain how you tested it.

## Important Rules

- Do not push directly to `main`.
- Do not push directly to `develop`.
- Do not force-push shared branches.
- Do not overwrite or delete another contributor's work.
- Keep pull requests focused.
- Do not commit passwords, tokens, private keys, or other secrets.
- Respect other contributors during code review.

## Reporting Bugs

Use the bug report form when possible.

Include enough information for another contributor to reproduce the problem.

## Security

Do not publicly disclose serious security vulnerabilities.

See `SECURITY.md` for information about reporting security issues.

## Code Review

Code review is part of contributing.

Reviewers may request changes, ask questions, or suggest alternatives. This is intended to improve the project and keep the codebase healthy.

Thanks for helping build develOS!
