# Security Policy

## Reporting a Vulnerability

Please do not publicly disclose serious security vulnerabilities in GitHub issues.

Use GitHub's private vulnerability reporting/security contact when available.

When reporting a vulnerability, provide:

- A description of the vulnerability
- Steps to reproduce it
- The affected component
- Potential impact
- Possible mitigation

Do not include passwords, API keys, private keys, tokens, or other secrets in public issues or pull requests.

## Scope

This policy applies to the develOS source code and official project infrastructure.

## Response

Security reports will be reviewed by the maintainers and investigated as soon as reasonably possible.
